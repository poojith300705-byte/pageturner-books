# 📚 PageTurner Books

A React-based Single Page Application (SPA) developed for the Full Stack Development course.

## Project Overview

PageTurner Books is a customer-facing bookstore application that allows users to browse books, filter them by genre, view detailed information, and maintain a wishlist.

---

## Features

- React Single Page Application
- Responsive UI
- Book Catalog (8 Books)
- Reusable BookCard Component
- Genre Filter
- Wishlist Functionality
- Wishlist Count in Header
- React useState
- React useEffect
- Simulated API Loading
- React Router
- Dynamic Book Details Page
- Responsive Design

## Installation

Clone the repository

```bash
git clone <repository-url>
```

Go to the project folder

```bash
cd pageturner-books
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
